# APIキー再発行の手順書（2026-08-12 作成）

平文で残っていた鍵2種類を、新しいものに取り替えるための手順です。
ブラウザを見ながら上から順に進められるように書いています。

---

## 0. 最初に知っておくこと

### 対象は2種類

| | 通称 | 何に使っているか |
|---|---|---|
| 鍵① | SerpAPI（サープAPI） | 航空券の検索結果の一部／予約先の候補／価格の相場感 |
| 鍵② | RapidAPI（ラピッドAPI） | 航空券の検索結果の一部 |

### 進める順番の原則

**「新しい鍵を先に作って書き込み、動作を確かめてから、古い鍵を止める」**

この順番なら、サイトが止まる時間をほぼゼロにできます。
逆に古い鍵を先に止めると、書き込みが終わるまでの数分間、機能が欠けます。

### 交換中に何が起きるか

Tobiraの航空券検索は、4つの情報源を同時に使い、**どれかが応答しなくても
残りで結果を出す**作りになっています。そのため片方の鍵が一時的に無効でも、
検索そのものが真っ白になることはありません。

| 状態 | 起きること | 検索は使えるか |
|---|---|---|
| 鍵①が無効な間 | 検索結果の件数が減る／予約先の候補が出ない／価格の相場感が出ない | 使える |
| 鍵②が無効な間 | 検索結果の件数が減る | 使える |
| 両方無効な間 | 検索結果の件数がかなり減る | 使える（結果が出ない場合あり） |

## 1. 事前確認（ウエマツさんにお願いします）

私は安全設定により `.env.local` を読めません。次の2行があるかだけ、
ご自身で確認してください。**中身の文字列は誰にも見せないでください。**

1. Macで `nomad-hopper` フォルダを開く
2. `.env.local` というファイルをテキストエディタで開く
3. 次で始まる行があるか目で確認する

- `SERPAPI_KEY=`
- `RAPIDAPI_KEY=`

両方あれば、そのまま手順2へ進めます。
どちらかが無ければ、その旨をお知らせください（書き込み先が変わります）。

## 2. 鍵① SerpAPI の再発行

### 2-1. 再発行の画面を開く

1. ブラウザで次を開く → https://serpapi.com/manage-api-key
2. ログインを求められたらログインする
3. 「Your API Key」（あなたのAPIキー）という見出しの画面が出ます

> この画面には現在の鍵と、鍵を作り直すボタンが並んでいます。
> ボタンの名前は「Regenerate」または「Reset」と表示されます。

### 2-2. 新しい鍵を作る

1. 作り直すボタンを押す
2. 「本当に作り直すか」と聞かれたら、はいを選ぶ
3. **新しい鍵が画面に表示されます。この画面を閉じずに手順3へ進んでください**

> ⚠️ SerpAPIは鍵を1つしか持てません。作り直した瞬間に古い鍵は無効になります。
> つまりここから手順3を終えるまでの数分間だけ、上の表の「鍵①が無効な間」の
> 状態になります。検索自体は使えます。

## 3. 鍵① を書き込む（2か所）

### 3-A. Macの中（開発用）

1. `nomad-hopper` フォルダの `.env.local` を開く
2. `SERPAPI_KEY=` で始まる行を探す
3. `=` より右側だけを、新しい鍵に置き換える
4. 保存して閉じる

### 3-B. 本番サイト（Vercel）

1. ブラウザで次を開く → https://vercel.com/dashboard
2. Tobira（tobira-world.jp）のプロジェクトを選ぶ
3. 上部の「Settings」（設定）を選ぶ
4. 左側の一覧から「Environment Variables」（環境変数）を選ぶ
5. 一覧の中から `SERPAPI_KEY` を探す
6. 右端のメニューから「Edit」（編集）を選ぶ
7. 値を新しい鍵に置き換えて保存する
8. **保存しただけでは本番に反映されません。**上部の「Deployments」（デプロイ）
   を開き、一番上のものを選んで「Redeploy」（再デプロイ）を実行する

---

## 4. 鍵② RapidAPI の再発行

### 4-1. 再発行の画面を開く

1. ブラウザで次を開く → https://rapidapi.com/developer/apps
2. ログインを求められたらログインする
3. アプリの一覧が出ます。Tobiraで使っているアプリを選ぶ
4. 「Security」（セキュリティ）または「Authorization」（認証）という項目を開く
5. 「App Key」（アプリキー）が表示されます

### 4-2. 新しい鍵を作る

RapidAPIは**新旧を一時的に併存できます**。次のどちらかを選んでください。

**推奨：新しいアプリを作る方法（サイトが一切止まりません）**
1. アプリ一覧の画面で「Create App」（アプリを作成）を選ぶ
2. 名前を付けて作成する（例: `tobira-2026-08`）
3. 新しいアプリの「App Key」を控える
4. 手順5で書き込み、動作確認まで済ませる
5. 確認できたら、古いアプリを削除する

**もう一つ：今のアプリの鍵を作り直す方法**
1. 「App Key」の横にある作り直すボタンを押す
2. 古い鍵はその場で無効になります（数分間、結果件数が減ります）

---

## 5. 鍵② を書き込む（2か所）

手順3とまったく同じ流れです。変数の名前だけが違います。

### 5-A. Macの中
`.env.local` の `RAPIDAPI_KEY=` の右側を新しい鍵に置き換えて保存

### 5-B. 本番サイト
Vercelの環境変数一覧から `RAPIDAPI_KEY` を選び、値を置き換えて保存 → 再デプロイ

---

## 6. 動作確認

1. https://tobira-world.jp を開く
2. いつもの検索を1回行う（例: 東京 → バンコク）
3. 次の3つを目で確認する
   - 検索結果が出ること
   - 結果を選んだときに予約先の候補が出ること（鍵①の確認）
   - 価格の相場感（安い・普通などの表示）が出ること（鍵①の確認）

うまくいかない場合は、Vercelの再デプロイが終わっているかを先に確認してください。

## 補足：今回の漏えいリスクについて

- この2つの鍵は、Macの中のファイルに平文で置かれていました
- **gitの履歴を全て調べた結果、一度もgitに入ったことはありません**
- したがってGitHubにも外部にも出ていません

外部に出た形跡はないため、再発行は「念のため」の位置づけです。
急ぐ必要はありませんが、平文で置かれていた事実は残るため、
取り替えておくのが確実です。
