# APIキー再発行の手順書（2026-08-12 全面改訂）

`.env.local` の内容がチャットに貼り付けられた事故への対応です。
中に入っていた鍵をすべて取り替えます。

**この手順書は途中で中断できます。** 1件ごとに独立しているので、
好きなところで止めて、後から続きを再開できます。

---

## 0. 最初に読むところ

### 全体の流れ

鍵1件につき、やることは同じ3ステップです。

1. **サービスの画面で新しい鍵を作る**（古い鍵はまだ消さない）
2. **Vercelの画面で書き換える**
3. **動作を確かめてから、古い鍵を消す**

この順番なら、本番サイトはほぼ止まりません。

### 書き込み先は「Vercel」1か所です

`.env.local` の先頭に `# Created by Vercel CLI` と書かれていました。
これは**Vercelに登録された内容を写し取っただけのファイル**という意味です。

つまり本体はVercel側にあります。**Vercelを直せば、それが本物の設定です。**
Macの中のファイルは写しなので、後からまとめて取り直せます（手順7）。

### 進捗チェックリスト

中断したときは、ここを見れば続きが分かります。

- [ ] 1. Anthropic（AIの頭脳）
- [ ] 2. SerpAPI（検索と予約先）
- [ ] 3. RapidAPI（検索の一部）
- [ ] 4. KV・Redis（保存データ）
- [ ] 5. Travelpayouts（収益の受け取り口）
- [ ] 6. Duffel（試験用・実害なし）
- [ ] 7. 本番への反映と動作確認
- [ ] 8. Macの中のファイルを取り直す

### 所要時間の目安

全部で **1時間5分** ほどです。1件ずつの目安は各章に書いています。

## 1. Anthropic（最優先・5分）

### なぜ最初か
使った分だけ課金され、**上限がありません**。悪用されたときの被害が最も大きい鍵です。

### 止まるもの
**止まりません。** 新旧を同時に持てるため、切り替えの瞬間もつながったままです。

（もし止まった場合に影響するのは、検索文の読み取り・AI分析・チャットなど、
AIを使う機能すべてです。）

### 手順

1. https://console.anthropic.com/settings/keys を開く
2. ログインする
3. 「Create Key」（キーを作成）を押す
4. 名前を聞かれたら分かるものを入れる（例: `tobira-2026-08`）
5. **新しい鍵が1回だけ表示されます。** この画面を閉じずに次へ
6. 手順1-Vへ進む

### 手順1-V（Vercelに書き込む）

1. https://vercel.com/dashboard を開く
2. Tobira（tobira-world.jp）のプロジェクトを選ぶ
3. 上の「Settings」（設定）を選ぶ
4. 左の一覧から「Environment Variables」（環境変数）を選ぶ
5. 一覧から `ANTHROPIC_API_KEY` を探す
6. 右端のメニューから「Edit」（編集）を選ぶ
7. 値を新しい鍵に置き換えて保存する

### 古い鍵を消す
**まだ消さないでください。** 手順7の動作確認が終わってからです。
消す場所は、手順1の同じ画面（キーの一覧）です。

---

## 2. SerpAPI（5分）

### なぜこの順位か
検索1回ごとに課金される従量制です。放置すると請求が伸びます。

### 止まるもの
**この1件だけ、数分間だけ欠けます。** SerpAPIは鍵を1つしか持てないため、
新しく作った瞬間に古い鍵が無効になります。

欠けるのは次の3つです。検索そのものは使えます。
- 検索結果の件数が少し減る
- 予約先の候補が出ない
- 価格の相場感（安い・普通などの表示）が出ない

### 手順

1. https://serpapi.com/manage-api-key を開く
2. ログインする
3. 「Your API Key」という見出しの画面が出ます
4. 鍵を作り直すボタンを押す（「Regenerate」または「Reset」と表示されます）
5. 確認を聞かれたら、はいを選ぶ
6. **新しい鍵が表示されます**
7. 手順1-Vと同じ流れで、Vercelの `SERPAPI_KEY` を書き換える

### 古い鍵を消す
作り直した時点で自動的に無効になります。**追加の作業は不要です。**

---

## 3. RapidAPI（10分）

### 止まるもの
**止まりません。**下の推奨方法なら、新旧が同時に生きています。

（影響するのは検索結果の件数だけです。）

### 手順（推奨：新しいアプリを作る方法）

1. https://rapidapi.com/developer/apps を開く
2. ログインする
3. アプリの一覧が出ます
4. 「Create App」（アプリを作成）を押す
5. 名前を付ける（例: `tobira-2026-08`）
6. 作成したアプリを開き、「Security」または「Authorization」という項目を選ぶ
7. 「App Key」（アプリキー）が表示されます。これが新しい鍵です
8. 手順1-Vと同じ流れで、Vercelの `RAPIDAPI_KEY` を書き換える

### 古い鍵を消す
手順7の動作確認が終わってから、古いアプリを削除してください。

> ⚠️ 新しいアプリでは、Tobiraが使っているAPI（Sky Scrapper）の契約を
> 選び直す必要がある場合があります。手順7の確認で検索結果が減っていたら、
> 新しいアプリ側でSky Scrapperを購読しているかを見てください。

## 4. KV・Redis（15分）

### なぜこの順位か
課金の心配は小さいですが、**保存されているデータを読み書きできる**鍵です。
価格の履歴や、通知の設定が入っています。

### 止まるもの
一時的に次が起きます。検索そのものは使えます。
- 同じ検索が少し遅くなる（一時保存が効かなくなるため）
- その間の価格の履歴が記録されない

### 対象

`.env.local` の中で、**`KV` で始まる行と `REDIS` で始まる行のすべて**です。
これらは1つのデータ保管庫に対する鍵で、まとめて取り替わります。

### 手順

1. https://vercel.com/dashboard を開く
2. 上の「Storage」（ストレージ）を選ぶ
3. Tobiraが使っている保管庫を選ぶ
4. 認証情報を作り直す項目を探す
   （「Rotate」「Reset credentials」「Regenerate token」などと表示されます。
   外部の管理画面へ移動するボタンが出る場合もあります）
5. 作り直すと、**Vercelの環境変数は自動で新しい値に更新されます**

> ⚠️ この1件だけは、サービス側の画面の作りが変わりやすい箇所です。
> それらしい項目が見つからない場合は、**画面に表示されている項目名を
> そのまま教えてください。**一緒に進めます。
>
> ⚠️ 「保管庫を作り直す」という選択肢は選ばないでください。
> **中に入っている価格の履歴と通知の設定が全部消えます。**
> 取り替えたいのは鍵だけです。

## 5. Travelpayouts（10分）

### 止まるもの
検索結果のうち、Travelpayouts経由の候補だけが一時的に減ります。

**収益は影響を受けません。** アフィリエイトのリンクは「marker=731864」という
別の番号で動いており、この鍵とは無関係です。**リンクは切れません。**

### 手順

1. https://www.travelpayouts.com/ を開いてログインする
2. 右上のアカウント名から「設定」または「プロフィール」を開く
3. 「API」または「APIトークン」という項目を探す
4. トークンを作り直す
5. 手順1-Vと同じ流れで、Vercelの `TRAVELPAYOUTS_TOKEN` を書き換える

## 6. Duffel（5分・急ぎません）

### なぜ最後か
この鍵は**試験用**でした。Tobiraのコードは、試験用の鍵を見つけると
**その情報源を自動的に使わない**作りになっています。

つまり**本番サイトには一切影響しておらず、悪用されても実害はありません。**
念のため取り替える、という位置づけです。

### 止まるもの
**何も止まりません。**

### 手順

1. https://app.duffel.com を開いてログインする
2. 「Developers」（開発者）または「Access tokens」（アクセストークン）を開く
3. 試験環境（Test）を選んだ状態で、新しいトークンを作る
4. 手順1-Vと同じ流れで、Vercelの `DUFFEL_API_KEY` を書き換える
5. 古いトークンを削除する

## 7. 本番への反映と動作確認（10分）

### 反映する

Vercelの環境変数は、**保存しただけでは本番に反映されません。**

1. https://vercel.com/dashboard でTobiraのプロジェクトを開く
2. 上の「Deployments」（デプロイ）を選ぶ
3. 一番上のものを選び、「Redeploy」（再デプロイ）を実行する
4. 完了まで1〜2分待つ

### 確認する

1. https://tobira-world.jp を開く
2. いつもの検索を1回行う（例: 東京 → バンコク）
3. 次の4つを目で確認する

- [ ] 検索結果が出る
- [ ] 検索文がきちんと解釈されている（Anthropicの確認）
- [ ] 結果を選ぶと予約先の候補が出る（SerpAPIの確認）
- [ ] 価格の相場感が表示される（SerpAPIの確認）

うまくいかないときは、再デプロイが終わっているかを最初に確認してください。

### 古い鍵を消す

ここまで確認できたら、保留にしていた古い鍵を消します。

- [ ] Anthropic のキー一覧から古いキーを削除
- [ ] RapidAPI の古いアプリを削除
- [ ] Duffel の古いトークンを削除

## 除外したもの：VERCEL_OIDC_TOKEN

**再発行は不要です。**

これはウエマツさんが発行したものではなく、**Vercelが自動で発行し、
短時間で自動的に失効する一時的な通行証**です。有効期限が切れれば使えなくなり、
必要なときにまた自動で作り直されます。手で再発行する画面もありません。

放置して問題ありません。

## 補足：この事故について

- 漏えいしたのは、Macの中のファイルをチャットに貼り付けたことによるものです
- **チャットから消しても漏えいは取り消せません。**取り替えることだけが対処です
- gitやGitHubには入っていません（履歴を全て確認済み）
- 今後 `.env` 系ファイルを私が読めないよう、安全設定で塞いであります
